Place a TOPSTEP dial container here to use it as a background template.

The app builds a custom watch face by replacing the background image inside a
template container. A template supplies the widget records and auxiliary blocks
that this project does not yet know how to generate from scratch.

No template is shipped with this app on purpose: the dial artwork and auxiliary
blocks inside a container are the vendor's content, and redistributing them is a
licensing question rather than a technical one. Add one locally if you have a
container you are entitled to use.

Accepted: a raw TOPSTEP file (starts with the ASCII bytes "TOPSTEP").
A .bin extracted from a dial package is usually exactly this.
